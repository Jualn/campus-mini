# common_page_icons

用于搜索页、消息页等通用入口的 SVG 图标。

建议映射：

- `activity.svg`：活动统一图标，复用原图标
- `exam.svg`：考试统一图标，复用原图标
- `post.svg`：动态广场 / 社区动态
- `system_notice.svg`：系统公告
- `interaction.svg`：互动消息
- `notification_empty.svg`：暂无通知空状态
- `message_center.svg`：消息中心入口/兜底
- `search.svg`：搜索框图标
- `clear.svg`：搜索框清除按钮
- `others.svg`：其他/通用入口，复用原图标

推荐路径：`/images/icons/common/`
