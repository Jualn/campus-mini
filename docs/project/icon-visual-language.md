# 图标视觉语言

## 设计方向

2026-09-30：针对通用图标、首页快捷入口、TabBar 三组默认/选中态、设置、消息分类及返回/更多控件进行资源与使用场景审查。设计目标是同一产品中的清晰、克制、可辨认；统一 Component 接口并不自动保证 SVG 视觉一致。

沿用已安装并保留 MIT 许可证的 Tabler Icons 3.48.0，不新增运行时依赖。依据 [官方图标设计规范](https://tabler.io/icons/icon-design-guide)，当前轮廓图标组采用 24×24 viewBox、2px 笔画、圆角端点与连接。使用同一套经过设计的形状，而不是把旧 SVG 的 stroke-width 强行改成一样。圆形、心形与眼睛的自然轮廓不同，不通过放大缩小让外接框完全相等；关注同一显示尺寸下的视觉重量和中心。

一致性以场景/同组为单位，不要求全项目都用线性图标或相同粗细。轻量操作、返回和列表辅助控件适合轮廓；TabBar、快捷入口、分类入口可以使用更有重量的面性或双色设计。允许不同组采用不同笔画或填充，同一组应协调图形占比、复杂度、圆角和配色；默认/选中态保持可识别的语义与主体轮廓，可以改变填充、颜色或适度的笔画重量。新增一组设计时同时记录资源规范并调整该组校验，不把当前轮廓批次的 2px 规则当成永久禁止面性图标的要求。场景差异通过受控资源和实际使用的状态表达，不引入任意路径/颜色配置。

| 场景 | 规则 |
|---|---|
| 帖子操作栏 | 评论气泡、心形、眼睛、分享箭头使用同系列灰蓝轮廓；点赞激活沿用同一心形轮廓并填红 |
| TabBar | 首页/消息/我的默认灰蓝轮廓，选中采用品牌蓝面性主体与白色内部细节；主体路径几何保持一致，不额外放大/上移；“我的”保留圆形用户轮廓 |
| 首页快捷入口 | 校园活动用日历事件，公共事项用带夹板的事项清单；两者采用深色轮廓与浅色填充的双色图形，增加入口辨识度；均为 48rpx 图标，84rpx 容器使用浅蓝/浅紫背景 |
| 返回 | 普通表面使用深灰蓝箭头；封面/图片上使用白色箭头与一致的深色半透明圆底；搜索及列表返回底色使用同一浅色表面语言 |
| 更多 | 同一三点轮廓，32rpx 图标；视觉不随父按钮原先 48–76rpx 的容器大小放大 |
| 设置 | 32rpx 同系列图标置于 56rpx 浅色圆角底；渠道行区分站内消息与微信服务号；扫码登录、编辑资料、反馈、版本分别用扫码、用户编辑、对话反馈、信息符号 |
| 消息 | 全部用收件箱、互动用双气泡、活动与事项用日历、系统用公告；筛选默认灰蓝、蓝底选中时白色，卡片保留分类色；筛选图标比卡片图标小；用户头像不替换为图标 |

普通控件颜色 `#52657d`，导航 `#20334d`，品牌蓝 `#2f7cf6`，未选中 TabBar `#64748b`，点赞 `#e45768`。外部 SVG image 不能依赖父级 CSS color：颜色写入静态资源，白色反相版本通过有实际调用点的 `inverse` state 选择，不新增任意路径/颜色接口。

业务图标与通用图标使用相同的图形家族，但继续遵守主包/分包所有权；设置、个人资料的资源留在各自分包。品牌、头像、封面、二维码、真实内容图片不被统一成线条图标。空状态使用同系列克制的轮廓，避免夸张的图标或复杂阴影。

Core 的来源记录见 [SOURCES](../../assets/icons/core/SOURCES.md)，业务资源与视觉修改见 [视觉资源来源](../../assets/icons/VISUAL_SOURCES.md)。架构与维护入口见 [Icon System](icon-system-v1.md)。本文件记录当前接受的设计规则；静态 SVG 对比板只能证明资源形状、笔画和颜色，不能替代原生运行时排版、SVG 解码或真机无障碍验收。

验证应覆盖 Registry/状态解析、资源来源与规范、调用点注册、类型检查、分包审计，以及受影响的通知、分享与活动回归。Developer Tools 编译、实际页面渲染和真机视觉验收单独报告。
