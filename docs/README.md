# 文档入口

按任务查找拥有该事实的文档，不需要通读整个 docs。

| 问题 | 入口与归属 |
|---|---|
| 如何开展项目工作 | [AGENTS.md](../AGENTS.md)：执行约束和阅读路由 |
| 原生小程序如何实现、验证和交付 | [Engineering](engineering/mini-program/README.md)：通用工程规则 |
| 本仓库采用什么配置、工具和能力 | [Project Profile](engineering/mini-program/project-profile.md)：有来源和核验状态的仓库事实 |
| 某项业务的入口、状态归属、交互和恢复 | [项目说明](project/README.md)：需要持续维护的项目决策 |
| 固定输入和保留的验证证据 | [输入与证据](operations/README.md)：锁文件、历史记录及适用范围 |
| 跨端字段、错误和权限协议 | [canonical OpenAPI](../../contracts/api/openapi.yaml)：同级 Contracts 仓库；项目文档只链接和解释消费影响 |

组件公开用法和资源来源留在所属目录：[评论面板](../components/comment-panel/README.md)、[分享图片](../utils/share_poster/README.md)、[通用图标](../assets/icons/common/README.md)、[详情图标](../assets/icons/detail/README.md)。

维护与检查见 [文档维护](engineering/mini-program/maintenance.md)。任务 Prompt、临时分析、日志和逐次交付总结不作为项目规则保存。历史 PASS 只适用于记录中的修订和环境；文档链接有效不等于接口、微信编译或真机已验证。
