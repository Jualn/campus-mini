# 数据流转架构图

## 三层数据架构

```
┌─────────────────────────────────────────────────────────────┐
│                    App 全局常量层                              │
│  BASE_URL, examTimelines, appConfig, ...                     │
│  📍 存储位置: app.js                                          │
│  ⏱️  生命周期: 应用级（运行期间不变）                          │
└─────────────────────────────────────────────────────────────┘
                            ↕️
┌─────────────────────────────────────────────────────────────┐
│                  Store 运行时状态层                            │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 认证信息                                              │   │
│  │ • token: string                                      │   │
│  │ • userInfo: { id, name, avatar, ... }              │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 权限与设置                                            │   │
│  │ • permissions: [ 'post:create', ... ]              │   │
│  │ • settings: { theme, notification, ... }           │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ UI 状态                                               │   │
│  │ • selectedTabIndex: number                          │   │
│  │ • scrollTops: { [route]: top }                      │   │
│  │ • badgeCount: number                                │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                               │
│  ✅ 响应式: 支持 store.watch() 监听变化                     │
│  ⏱️  生命周期: 运行时（页面刷新丢失）                        │
│  📍 存储位置: 内存                                            │
└─────────────────────────────────────────────────────────────┘
                            ↕️
┌─────────────────────────────────────────────────────────────┐
│              Storage 持久化存储层                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 必须持久化                                            │   │
│  │ • token: string                    (认证凭证)       │   │
│  │ • userInfo: object                 (用户基础信息)   │   │
│  │ • permissions: array               (用户权限)       │   │
│  │ • settings: object                 (用户设置)       │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                               │
│  ✅ 持久化: wx.setStorageSync 本地存储                      │
│  ❌ 响应式: 无法触发 UI 自动更新                            │
│  ⏱️  生命周期: 跨会话（小程序卸载才清空）                    │
│  📍 存储位置: 本地磁盘                                        │
└─────────────────────────────────────────────────────────────┘
```

## 完整数据流转流程

### 1️⃣ 用户首次登录流程

```
┌──────────────────┐
│  用户点击登录     │
└────────┬─────────┘
         │
         ↓
┌──────────────────────────────────┐
│  调用 auth.ensureLogin()         │
└────────┬─────────────────────────┘
         │
         ↓
┌──────────────────────────────────────────────┐
│  wxLogin() 获取 wx.login() code              │
└────────┬─────────────────────────────────────┘
         │
         ↓
┌──────────────────────────────────────────────────────────┐
│  POST /auth/login { code }                               │
│                                                          │
│  后端返回:                                               │
│  {                                                       │
│    token,          ← JWT或session token               │
│    userInfo,       ← { id, name, avatar, ... }        │
│    permissions,    ← [ 'post:create', ... ]           │
│    settings        ← { theme, notification, ... }     │
│  }                                                      │
└────────┬─────────────────────────────────────────────────┘
         │
         ↓
    ┌────┴────┐
    │  双重保存 │
    └────┬────┘
         │
    ┌────┴────────────────────────────────┐
    │                                      │
    ↓                                      ↓
┌─────────────────┐              ┌──────────────────┐
│  Storage 保存    │              │  Store 更新      │
│  (持久化)        │              │  (运行时)        │
│                 │              │                  │
│ token           │              │ token            │
│ userInfo        │              │ userInfo         │
│ permissions     │              │ permissions      │
│ settings        │              │ settings         │
│                 │              │                  │
│ wx.setStorage   │              │ store.setState() │
└─────────────────┘              └──────┬───────────┘
                                        │
                                        ↓
                              ┌──────────────────────┐
                              │ emit LOGIN_SUCCESS   │
                              │ 更新UI组件状态        │
                              └──────────────────────┘
                                        │
                                        ↓
                              ┌──────────────────────┐
                              │ 跳转到首页           │
                              └──────────────────────┘
```

### 2️⃣ App冷启动恢复登录状态

```
┌──────────────────┐
│  App.onLaunch()  │
└────────┬─────────┘
         │
         ↓
┌────────────────────────────────────┐
│  调用 initUserInfo()               │
└────────┬───────────────────────────┘
         │
         ↓
┌────────────────────────────────────────────┐
│  从 Storage 读取                           │
│  • token                                   │
│  • userInfo                                │
│  • permissions                             │
│  • settings                                │
│                                            │
│  如果 token && userInfo 存在 ✅            │
└────────┬───────────────────────────────────┘
         │
         ↓
┌────────────────────────────────────────────┐
│  更新到 Store                              │
│  store.setState({                          │
│    token, userInfo,                        │
│    permissions, settings                   │
│  })                                        │
└────────┬───────────────────────────────────┘
         │
         ↓
┌────────────────────────────────────────────┐
│  用户已登录状态恢复 ✅                    │
│  • 无需重新登录                            │
│  • 直接进入首页                            │
│  • 可以正常使用应用                        │
└────────────────────────────────────────────┘

❌ 如果 token 为空或过期:
   直接进入登录页重新认证
```

### 3️⃣ UI状态管理流程 (以选中tab为例)

```
┌──────────────────────────────┐

         │
         ↓
┌──────────────────────────────────────┐
│  custom-tab-bar 点击事件触发         │
└────────┬─────────────────────────────┘
         │
         ↓
┌──────────────────────────────────────────────────┐
│  store.set('selectedTabIndex', 1)               │
│                                                  │
│  内部触发流程:                                   │
│  1. this._state['selectedTabIndex'] = 1         │
│  2. 触发所有监听 watch 回调                     │
└────────┬─────────────────────────────────────────┘
         │
         ↓
    ┌────┴─────────────────────────────┐
    │  所有监听此字段的页面收到通知     │
    └────┬─────────────────────────────┘
         │
    ┌────┴──────────┬──────────────┬──────────────┐
    │               │              │              │
    ↓               ↓              ↓              ↓
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────┐
│ pages/   │  │ pages/   │  │ pages/   │  │ custom-tab-  │
│ index    │  │ message  │  │ me       │  │ bar          │
│          │  │          │  │          │  │              │
│ setData  │  │ setData  │  │ setData  │  │ setData      │
│ 更新UI   │  │ 更新UI   │  │ 更新UI   │  │ 更新UI       │
└──────────┘  └──────────┘  └──────────┘  └──────────────┘

⚠️ 注意: scrollTops 不会被保存到 Storage
         只存在 Store 中，刷新会丢失
```

### 4️⃣ 权限检查流程

```
┌──────────────────────────────────┐
│  页面需要发布文章                 │
└────────┬─────────────────────────┘
         │
         ↓
┌──────────────────────────────────────────┐
│  import { hasPermission }                │
│  from './store/helper'                   │
└────────┬─────────────────────────────────┘
         │
         ↓
┌──────────────────────────────────────────┐
│  if (hasPermission('post:create'))       │
└────────┬─────────────────────────────────┘
         │
         ↓
    ┌────┴─────────────────────────────┐
    │  内部逻辑                         │
    │  1. permissions =                │
    │     store.get('permissions')     │
    │  2. return                        │
    │     permissions.includes(        │
    │       'post:create'              │
    │     )                             │
    └────┬─────────────────────────────┘
         │
    ┌────┴──────────────────────────┐
    │                               │
    ↓ YES                           ↓ NO
┌──────────────────┐        ┌──────────────────┐
│ 显示发布按钮     │        │ 隐藏发布按钮     │
│ 允许发布操作     │        │ 提示权限不足     │
└──────────────────┘        └──────────────────┘
```

## 数据访问速度对比

```
┌─────────────────────────────────────────────────────────────┐
│  访问数据的性能特征                                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  App.globalData         ⚡⚡⚡⚡⚡  最快（直接内存）            │
│                                                              │
│  Store.get()            ⚡⚡⚡⚡⚡  很快（内存）              │
│                                                              │
│  Storage.get()          ⚡⚡⚡     慢（磁盘I/O）            │
│                                                              │
└─────────────────────────────────────────────────────────────┘

💡 建议:
  - 频繁访问的数据: 使用 Store
  - 初始化只读: 使用 App.globalData
  - 需要跨会话: 使用 Storage
```

## 应该使用哪个层？决策树

```
                    需要存储数据?
                       /  \
                     是    否
                    /        \
                   ↓          ↓
            是否需要   ← 不需要 (使用局部变量)
            持久化?    
           /      \
         是        否
        ↓          ↓
     STORAGE     STORE
     (磁盘)      (内存)
                   │
                ← 需要响应式?
                  /      \
                是        否
               ↓          ↓
           STORE      STORE
         (watch)   (get/set)


Q1: 需要存储数据?
  ✅ YES  → 到Q2
  ❌ NO   → 使用局部变量或方法参数

Q2: 需要持久化(关闭小程序仍保存)?
  ✅ YES  → 用 Storage
           例: token, userInfo, settings
  ❌ NO   → 到Q3

Q3: 需要响应式(页面自动更新)?
  ✅ YES  → 用 Store.watch()
           例: selectedTabIndex, UI状态
  ❌ NO   → Store(不监听)或Storage
           例: 缓存数据、统计信息
```
