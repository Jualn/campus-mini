# 分享图片

> 状态：保留的海报设计说明；2026-09-13 整理了文档，未复验绘图实现、超时数值和真机结果。下面的尺寸、视觉结构与回归范围是设计记录，变更前核对实现。

页面负责分享对象、原生分享回调和唯一的隐藏 `#posterCanvas`。`post-card` 只发出 `{ postId }`；列表页通过 `usePostActions` 组合 `useSharePoster`，详情页直接组合后者。

`useSharePoster` 接收不可变的数据快照、内容版本 key、标题、路径及绘图函数。`ShareTask` 串行使用画布，只发布最新任务的结果，销毁后不再更新页面。同一 key 的成功图片在当前页面内复用；失败可以重试。当前任务失败时，通过项目 logger 记录页面路径（不含查询参数）和错误消息；过期任务不报告，日志失败不阻断后续重试。任务类通过回调报告异常，保持与微信日志 API 解耦。

状态为 `idle → loading → ready / error`。面板在生成中禁用分享与保存；失败可重试，也可使用默认封面分享内容。右上角原生分享在图片未就绪时使用默认封面，路径与标题仍属于当前对象。面板单独管理图片解码与保存状态。

模板返回 `Promise<string>`，覆盖绘图和临时文件导出全过程。图片加载与导出分别最多等待 8 秒，Canvas 查询最多等待 3 秒。图片资源失败时，帖子和活动降级为文字布局；查询或导出失败由页面进入 error 状态。输出固定为 1080 × 864，不按设备 DPR 再放大。

`posterCanvas.ts` 提供绘图、换行、导出及 `optionalImage` 图片失败降级。帖子模板留在主包；活动、考试模板留在各自分包。三类模板保持各自的视觉结构，正文和字段限制行数、宽度，防止溢出。

活动保留有封面的渐变图、活动标签、时间/地点/人数信息条，以及无封面的蓝色顶条和信息色块，边距 32px；标签与信息行保持对齐，长地点限制行数。考试保留红色顶条和考试标签、简介及橙蓝时间块；当前详情没有等级/类型标签字段，不补造原示例标签。时间块显示详情中前两个提供了日期的节点，保留原标签，不推断报名状态或未提供的时间。

帖子视觉结构：有图时首图等比裁切铺满上部，最多四张缩略图叠在右下，渐变衔接头像、昵称、日期和三行摘要；纯文字保留蓝色顶条、浅色引号、五行正文及底部署名和按钮。有图版文字边距为 32px；头像与正文保持间距，限制长昵称和底部区域以避免溢出。首图、头像、缩略图并行加载，首图失败时转为文字布局。帖子、活动、考试均不传额外 `title`，由微信决定默认标题呈现。

候选回归：[分享回归脚本](../../scripts/test-share.mjs)，命令为 `node scripts/test-share.mjs`（本轮未运行）。原文记录的覆盖范围为异步错配、串行、销毁、失败重试、导出、图片超时、换行与分享兜底。浏览器 Canvas 预览可以检查排版，但不能代替微信开发者工具与真机上的 Canvas、转发、相册权限和弹层手势验收。
